Mantella - Anthropic API v1.0

Unofficial modification to Mantella, dated 2026-10-21: adds Anthropic (Official) as an
LLM service. Not endorsed by the Mantella authors or by Anthropic.

BUILDING
Run setup_backend.py using CPython 3.11 against a supported Mantella.exe; see INSTALL.txt.
No third-party Python packages are needed. Source/backend/build-contract.json records the
supported input executables, the source hashes and the expected output hashes.

No Mantella executable, bundled runtime or voice assets are redistributed here. Obtain
them from the original Mantella installation. Setup creates a copy and does not alter the
original or user configuration. The hash guards establish release compatibility, not
restrictions on license rights: developers may change the source and build contract for
their own builds. Redistributing the resulting full executable requires reviewing its
bundled components and satisfying their source and notice requirements separately.
Retain applicable AGPL notices and source access when serving remote users.
